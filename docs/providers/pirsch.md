# Pirsch

Follow these steps to configure Pirsch for Metrix.

## Connecting to Pirsch

1. Log in to your [Pirsch](https://pirsch.io/) dashboard.
2. Create an OAuth client and note the **Client ID** and **Client Secret**.
3. In Metrix, create a Source and choose **Pirsch**.
4. Paste the **Client ID** and **Client Secret**.
5. Enter (or select) your **Domain ID**.
6. Save and Connect.
