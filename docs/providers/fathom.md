# Fathom
Follow these steps to configure Fathom Analytics for Metrix.

## Connecting to Fathom Analytics

### Connect to the Fathom API
1. Log in to your [Fathom Dashboard](https://app.usefathom.com/settings/api).
1. Go to the **API** section.
1. Generate a new API key with **Read Access** to all sites, so Metrix can list the sites available to the key.
1. Copy the API key and paste it into the **API Key** field in Metrix.
1. Leave **Enabled** off and save the Source. Reopen it and click **Connect**.
1. Open the **Provider** tab and click the refresh button beside **Site ID** to load the available sites.
1. Select the intended **Site ID**, turn **Enabled** on, and save.
1. Reopen the Source and click **Connect** if it is shown as disconnected after saving the settings. Confirm a widget can load data for the selected site.
