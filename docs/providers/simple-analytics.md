# Simple Analytics

Follow these steps to configure Simple Analytics for Metrix.

## Connecting to Simple Analytics

1. Log in to [Simple Analytics](https://www.simpleanalytics.com/).
2. In Metrix, create a Source and choose **Simple Analytics**.
3. Enter your site **Hostname** (e.g. `example.com`).
4. For private websites, paste an **API Key**. Public websites can leave it blank.
5. Optionally set **Timezone** for histogram data (e.g. `UTC` or `Europe/Amsterdam`).
6. Save and Connect.
